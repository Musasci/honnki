Tools

ここはオーナー向けの更新ツールです。作ったファイルをGitHubにアップロードするまで、サイトは変わりません。

0) 更新パック（おすすめ）

ZIPを書き出して展開 → GitHubの「Upload files」でドラッグするだけ。
このパックは posts.json / videos.json / site.json と、あなたが追加・編集したファイルだけを含みます（既存ファイルは削除されません）。

（任意）手元のファイルを読み込む：posts.json / videos.json / site.json / post-*.md / video-*.mp4 / img-*.png など

ここにファイルをドロップ（クリックでも選べます）

個別ダウンロード

必要なものだけ書き出したい場合。

運用メモ

  • GitHubで上書きアップロードしてOK（古いファイルは消えません）。
  • 動画ファイルはサイズが大きい場合があります。必要ならYouTube運用が軽いです。
  • Toolsページ自体は公開されますが、GitHubの権限がない人はサイトを更新できません。

1) ブログ

記事を新規作成・編集して、post-*.md と posts.json を更新します。

プレビュー

2) 動画

YouTubeリンク、または動画ファイル（mp4/webm）を追加して videos.json を更新します。

ファイル名は自動で video-<slug>.mp4 / poster-<slug>.jpg などになります。

3) 連絡設定（site.json）

「メール起動」または「Googleフォーム埋め込み」を選べます。

送受信を簡便にするなら：フォーム＝受信専用、返信はメールで（必要なときだけ）がおすすめです。
