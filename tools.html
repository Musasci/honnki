反映方法

  1. ダウンロードした site.json を GitHub の site.json に置き換え
  2. 保存すると contact.html のボタンが自動であなたのメールに向きます

④ 非公開メッセージを「設定ほぼゼロ」で動かす

このサイトの contact.html は Netlify Forms に対応しています。サーバの鍵（APIキー）をリポジトリに入れずに動かせます。

  1. Netlifyでこのリポジトリをデプロイ（ドラッグ＆ドロップでもOK）
  2. デプロイ後、Netlifyの管理画面で Forms にフォームが見えることを確認
  3. 通知（Email notifications） にあなたの受信アドレスを設定

迷惑送信対策：ハニーポットを標準で有効化しています。追加で reCAPTCHA も設定できます。

⑤ 最低限のセキュリティ運用チェック

  • 住所・勤務先の詳細・行動パターンが特定できる情報は載せない
  • 写真はEXIF削除（位置情報や撮影日時が残ることがあります）
  • 公開リポジトリにAPIキー/限定URLを入れない

※ GitHub Pages だけだとHTTPヘッダ（CSP等）を強化できません。必要なら Cloudflare Pages 推奨。
